# AC-audio
使部分OJ网站，当你AC题目时，发出特殊的音效

# 已支持网站
1. [洛谷](https://www.luogu.com.cn/)；
2. [牛客](https://ac.nowcoder.com/)；
3. [QOJ](https://qoj.ac/)；
4. [Codeforces](https://codeforces.com/)；

# 使用方法

1. 添加油猴插件；
2. 导入对应网站的js插件；
